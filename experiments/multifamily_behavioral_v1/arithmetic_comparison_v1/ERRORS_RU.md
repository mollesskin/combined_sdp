# Журнал ошибок реализации

- Начальная JS-проверка node --check обнаружила недостающую закрывающую скобку массива сценариев token; исправлено до исполнения измерений.
- При первом добавлении расширенного экспорта команда использовала путь относительно корня при cwd=project и получила FileNotFoundError/mv/cat path errors. Контракты и baseline не затронуты. Вслед за этим неизменённый measure.js повторно выполнился в прежний run1; затем предварительный набор сохранён в initial_instrumentation. Итоговые run1/run2 выполнены после исправления cwd и расширения экспорта.
- Solidity compiler warnings сохранены в compile.log и run2_compile.log; это предупреждения legacy-исходников/неиспользуемых функций и helper, не compilation failures.
- Инфраструктурные ошибки исполнения не превращаются в защиту; итоговый analyze.py требует их отсутствия и отдельно проверяет receipt status.
