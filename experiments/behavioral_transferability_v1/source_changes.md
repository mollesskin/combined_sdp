# Source changes

Original UC02/UC03 V0 copies are byte-identical. Hashes/paths are in source_manifest.json and minimal unified V1/V2/V3 diffs under variants/<ID>/. Only each benchmark-annotated call statement is affected. V1 captures and requires its CALL status. V2 retains that original call and appends exactly the strict return decoder from frozen UC01 (indentation adapted). V3 has both. No storage/public function, arguments, loop bounds, scaling, access control or unrelated checks added. Full compiled ABI comparisons are saved per contract, not asserted to prove behavior.

New synthetic TransferFromToken adds required approve/allowance and transferFrom behavior to support these baseline APIs, with exactly the previous three modes. It is compiled with the same compiler as each candidate. The harness’s generic chain/trace/compile helpers are copied into this new phase from UC01; the original files are not imported or edited. Contract-specific adapter/state observation replaces UC01 bank deposit/holder setup with token funding/approval and matching arrays. I2/E are N/A; balances and allowance are observed explicitly. See source_applicability.md for pre-run differences and protocol.md for requirements. This is a test-fixture/measurement adaptation, not a baseline repair.
