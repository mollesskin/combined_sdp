## Adaptations documented BEFORE coding/runs

UC01 I2 and consumed-entitlement E are **not applicable**, stored blank/N/A, never zero or a fictitious ledger. TransferFrom allowance is an observable token authorization budget, not a replacement user entitlement or a token liability. Success must debit exactly a allowance; failed atomic operation must preserve it. This is an explicit contract-specific extension of accounting checks in I1/I4/I6, not identical invariant text/count to UC01. Record before/after balances and allowance.
